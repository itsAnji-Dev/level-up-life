# Level Up Life Ops

A gamified productivity web app. Complete real-life missions, earn rewards, and unlock loot in a mobile-game-style interface.

**Live:** https://itsanji-dev.github.io/level-up-life/
Best viewed in Chrome on a phone, in landscape.

## Features
- Daily and boss missions with XP, levels, ranks and streaks
- Loot crates with rarity tiers and a guaranteed rare drop
- Store, loadout and collection
- 3D animated character and photo background
- Friends and leaderboard
- Optional cloud save with Google sign-in

## Tech
HTML, CSS and JavaScript (single file), three.js, Firebase.
Hosted free on GitHub Pages.
